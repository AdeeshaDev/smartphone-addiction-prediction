# Smartphone Addiction Prediction Using Machine Learning

This project predicts smartphone addiction using user behaviour data.

## Dataset

The dataset used in this project is the Smartphone Usage and Addiction Analysis dataset from Kaggle.

## Target Variable

The target variable is `addicted_label`.

- 0 = Not addicted
- 1 = Addicted

## Models Used

- Logistic Regression
- K-Nearest Neighbours (KNN)

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- F1-score
- Confusion Matrix

## Best Model

Logistic Regression was selected as the best-performing model because it achieved higher accuracy and F1-score than KNN.
